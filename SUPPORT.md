# Support

Kranz is an early-stage open-source project.

- Use GitHub Discussions for setup questions and usage guidance once
  Discussions are enabled.
- Use a GitHub issue for reproducible bugs and narrowly scoped feature
  requests.
- Use private vulnerability reporting for security concerns.

Only the latest released minor line is supported. There is no guaranteed
response time or production SLA. Include `kranz --version`, the operating
system, backend CLI/version, sandbox mode, and a redacted reproduction when
asking for help. Never attach credentials, raw authentication files, or
unredacted mission transcripts.
