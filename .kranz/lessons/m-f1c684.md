Enable tokio's `test-util` feature in a crate's `[dev-dependencies]` (e.g. `tokio = { workspace = true, features = ["test-util"] }`) before writing virtual-time async tests — the workspace's tokio `"full"` feature set does NOT include `test-util`, so `tokio::time::pause`/`advance` and `#[tokio::test(start_paused = true)]` won't compile without it. When a feature's testable behavior is a timeout/idle/interval path, spec this dev-dep addition up front so the worker doesn't discover it mid-run.
