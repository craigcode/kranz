A single durable, repo-specific lesson worth carrying forward: the `cargo fmt --all --check` gate cost a full fix cycle (ms-2-fix-1-1) because workers reported clippy-clean but hadn't run fmt, and rustfmt reflows long `assert!`/match-arm lines in new Rust test code.

Pin `cargo fmt --all --check` (exit 0) into every code-touching feature's validationCriteria as a distinct requirement from clippy — in this Rust workspace, workers habitually run `cargo clippy` but skip `cargo fmt --all --check`, and rustfmt reflows long assert!/match-arm lines in freshly-added test files, so the a11-style formatting gate fails at milestone validation and burns a fix cycle even when clippy and all tests are green.
