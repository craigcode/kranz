When a feature spec directs the worker to create a helper/validator/regression script (e.g. `check-*.sh` alongside the deliverable), add that script's exact path to the plan's `touchSet` — Kranz's milestone validator raises an out-of-contract-write finding for any committed file outside the touchSet globs, so spec-directed, benign scripts still burn a fix cycle if their paths weren't enumerated up front.
