For any validation-contract command that runs the dashboard suite (`npm --prefix apps/dashboard test ...`), make it install deps first — e.g. `npm --prefix apps/dashboard ci >/dev/null 2>&1; npm --prefix apps/dashboard test -- <filter>`. The checkout ships no `apps/dashboard/node_modules`, so a bare vitest command dies with `sh: vitest: command not found` and the assertion false-fails on fully-correct code (it forced a waiver round and muddied an f-2-3 respawn this mission). Rust `cargo test` commands need no such preflight — this is dashboard-only.
