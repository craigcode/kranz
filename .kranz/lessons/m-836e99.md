Inspect worker output from the mission branch ref (`kranz/mission-m-<id>` or the worker's commit SHA), never from the orchestrator's own `HEAD`/working tree — the orchestrator checkout stays on `main` (pre-mission base), so `git show HEAD:<file>`, `grep src`, and `git status` all read stale pre-deletion content and will falsely look like the worker did nothing. Likewise treat a `main..HEAD` diff stat full of unrelated deletions as a moving-base display artifact (main advanced after branch-off), not mission scope; use `git show <branch>:<file>`, `git grep <pattern> <branch>`, and `$KRANZ_BASE_SHA`-pinned diffs to judge.
