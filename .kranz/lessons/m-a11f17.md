PipelineView now defaults to the Actionable lens, which hides `landed`/`abandoned`/`queued`/`running`/`drafting` rows; any future dashboard test (or consumer) that asserts on a non-actionable stage row must first switch to the All lens (e.g. `fireEvent.click(screen.getByText('All'))`) or the row won't be in the DOM — several existing PipelineView tests had to be adapted this way.
