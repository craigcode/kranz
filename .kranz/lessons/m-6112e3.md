In feature specs, tell workers to run only filtered engine tests (`cargo test -p kranz-engine --lib <prefix>` or `--test <file> <name>`) and not the unfiltered `cargo test -p kranz-engine --lib`. The full engine lib suite can run past a worker's 30-minute command limit, and `timeout` isn't installed on the macOS host, so a worker that runs it ends with an aborted partial run and uncommitted edits.
