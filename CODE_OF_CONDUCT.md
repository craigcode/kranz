# Code of conduct

Kranz is committed to a respectful, harassment-free project community.

Be constructive, assume good intent while discussing ideas, respect different
experience levels and backgrounds, and focus criticism on the work rather than
the person. Harassment, threats, discriminatory language, deliberate
intimidation, doxxing, and publishing another person's private information are
not acceptable.

Project maintainers may edit or remove contributions and may temporarily or
permanently restrict participation when behavior harms the community. Report
conduct concerns privately to the maintainers through the repository owner's
GitHub profile. Reports will be handled as confidentially as practical.

This policy applies in project spaces and when representing the project in
public spaces.
